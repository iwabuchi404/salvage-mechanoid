R0〜R6 で分離された責務境界。各フェーズが次のフェーズの前提となっている。

R0: フロア遷移失敗契約

  • 対象: FloorManager, Game.regenerateFloor
  • 成果: 生成失敗時に旧フロアを維持、不整合を防止

R1: Enemy描画デッドコード除去

  • 対象: Enemy.ts の TURRET 残骸
  • 成果: EnemyVisualProfile で表示設定を純粋データ化

R2: Enemy描画ライフサイクル分離

  • 対象: Enemy ↔ PixiJS/Renderer
  • 成果: EnemyPresentation が描画を所有、Enemy.ts はゲーム状態のみ

R3: Enemy AI Strategy分離

  • 対象: Enemy.ts の AI 分岐
  • 成果: Static/Patrol/Guard/Aggressive の Strategy 化

R4: Entity生成Factory分離

  • 対象: Game.registerResourceEntities
  • 成果: EnemyFactory/ItemFactory/ObstacleFactory へ集約

R5: Room/Doorwayデータ境界

  • 対象: WorldSystem のフロアデータ
  • 成果: FloorSnapshot 単位で Room/Corridor/Doorway を同一世代保持

R6: FOV/Interaction接続

  • 対象: FOVSystem, InteractionQuery/Executor
  • 成果: tile_visibility_changed に roomId 含む、距離/active 境界
